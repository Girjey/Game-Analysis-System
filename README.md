
Game Balance Analysis System
Desktop-приложение для симуляции, сравнения и математического анализа боевого баланса игровых объектов в жанре RPG.

---

* Приложение позволяет моделировать пошаговые бои на основе детерминированных и вероятностных формул, рассчитывать димишинг брони, влияние усталости, точности и износа предметов, а также проводить симуляции методом Монте-Карло (100+ итераций) для определения реального WinRate и выявления дизбаланса.
* Мультижанровость
* Первоначальная программа заточена под жанр PRG, но при небольших модификациях формул она будет эффективна в иных жанрах.
* Функционал
* База данных(3 таблицы): Игровые предметы / Оружие и Броня (Item), Профиль боевой единицы / Героя (Hero / BattleUnit), Профиль противника (Enemy)
Управление пресетами: Добавление, редактирование, удаление, сохранение и загрузка параметров через JSON (nlohmann::json).
Боевой движок (CombatEngine): Симуляция боев с учетом инициативы (CoinFlip), димишинга защиты, расхода/регенерации стамины, прочности предметов и критов.
Визуализация & Логирование: Генерация полного (детализация каждого удара/крита/блока) и укороченного лога боя.
LLM-Аналитика: Автоматический разбор 100+ симуляций боев с помощью локальных ИИ-моделей (Ollama) и выдача рекомендаций по нерфу/баффу характеристик.

* Режимы Логирования
* Система поддерживает два уровня детализации боевых отчетов:
* Укороченный (Short Log): Итоговый счет побед/поражений, динамика HP по ходам, триггеры критов и их урон.
* Полный (Full Log): Все события укороченного лога + заблокированный броней урон, промахи, удары в состоянии усталости, момент наступления истощения, износ прочности.
Сборка и запуск
Требования:
* Компилятор с поддержкой C++17 или выше (GCC, Clang, MSVC)
* CMake 3.15+
* Библиотека nlohmann/json
