
# Game Balance Analysis System

### Desktop-приложение для симуляции, сравнения и математического анализа боевого баланса игровых объектов в жанре RPG.

<img width="692" height="388" alt="gif 1 game analysis system (1)" src="https://github.com/user-attachments/assets/d65779ca-a85f-4b70-bd27-2ebf0885e555" />

### Core Idea
* Главная особенность: Автоматизация и глубокая математическая симуляция пошаговых боев на основе детерминированных и вероятностных формул. Система рассчитывает диминишинг брони, влияние усталости, точность, износ предметов и проводит симуляции методом Монте-Карло (100+ итераций) для определения реального WinRate и выявления дисбаланса.

* Назначение: Инструмент для геймдизайнеров и балансировщиков, позволяющий быстро валидировать боевые характеристики юнитов и снаряжения.

* Мультижанровость: Базовый функционал заточен под RPG-механики, однако благодаря модульной архитектуре и гибким формулам легко адаптируется под другие жанры (Turn-based Strategy, Tactical RPG, Auto-battler).

Статус: *🚧 В разработке (Полишинг и проверка рабочего билда)*

### Пресеты (База данных):
* Item (Игровые предметы): Оружие, экипировка и броня с характеристиками прочности, защиты и износа.

* Hero / BattleUnit (Профиль героя): Полный сет характеристик боевой единицы (HP, стамина, инициатива, шанс и множитель критического урона).

* Enemy (Профиль противника): Пресеты врагов и боссов с настраиваемыми парами характеристик и паттернами поведения.

### Геймдизайн и Механики
*Панель управления и Боевой движок*

* Боевой движок (CombatEngine): Пошаговая симуляция боя с учётом инициативы (CoinFlip), диминишинга защиты, расхода и регенерации стамины, прочности предметов и критических попаданий.

* Управление пресетами: Полный цикл CRUD (добавление, редактирование, удаление, сохранение и загрузка) конфигураций и параметров через JSON (nlohmann::json).

* LLM-Аналитика: Автоматический разбор массива из 100+ симуляций с помощью интеграции с локальными ИИ-моделями (Ollama). Модель анализирует логи и выдает конкретные рекомендации по баффу или нерфу параметров.

### 2. Логирование и Технический Стек

* Укороченный (Short Log): Итоговый счёт побед/поражений, динамика изменения HP по ходам, триггеры критических ударов и суммарный урон.

* Полный (Full Log): Включает всё из укороченного лога + детальную раскладку по заблокированному броней урону, промахам, атакам в состоянии истощения, моменту наступления усталости и износу экипировки.

### Технический Стек:

* Язык программирования: C++17 / C++20 (GCC, Clang, MSVC).

* Система сборки: CMake 3.15+.

* Библиотеки и Зависимости: nlohmann/json (для сериализации и хранения пресетов), Ollama API (для локального ИИ-анализа).
